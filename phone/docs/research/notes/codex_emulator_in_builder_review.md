1. **P1 — Loopback binding does not authenticate device control.** [Makefile:42](phone/Makefile:42) correctly restricts listening, but upstream’s [WebSocket handler](https://raw.githubusercontent.com/NetrisTV/ws-scrcpy/cd6cea6ebde17af6685c2b325183fc24bef9d52b/src/server/services/WebSocketServer.ts) checks neither Origin/Host nor a token. **Evidence:** shell/control endpoints accept unauthenticated connections. **Inference:** hostile websites can control connected devices where browser local-network restrictions permit access. Add authenticated upgrades and Origin/Host validation; Builder’s own protections do not cover port 8000.

2. **P1 — Builder opens the pane before the server exists.** [builder.toml:6](phone/builder.toml:6) retains `kind="app"`. **Evidence:** `bot.rs` declares readiness after two seconds whenever `make` remains alive, including during downloads, boot and compilation. **Consequence:** the iframe can load a connection-error page requiring manual reload; indefinite boot waits also bypass the 900-second timeout. Check HTTP readiness before reporting ready.

3. **P2 — Port fallback breaks the page.** [Makefile:30](phone/Makefile:30), [builder.toml:13](phone/builder.toml:13). **Evidence:** launcher chooses another port when 8000 is occupied; ws-scrcpy and the encoded WebSocket URL remain on 8000, while `page_url()` and frame CSP use the allocated port. Honor `PORT` throughout or explicitly reject collisions.

4. **P2 — Existing devices are mishandled and can be stopped unexpectedly.** [Makefile:27](phone/Makefile:27), [Makefile:34](phone/Makefile:34). **Evidence:** Builder invokes `stop` before its first `dev`; unqualified `adb emu kill` can terminate an unrelated emulator. Other commands select any sole device, fail with multiple devices, or install onto a physical phone while the page targets `emulator-5554`. Select a consistent serial and track ownership.

5. **P2 — Previously configured projects skip required emulator setup.** [Makefile:20](phone/Makefile:20). **Evidence:** the existing `.builder-setup-done` marker skips the new AVD creation. With no AVD, emulator startup fails in the background and `adb wait-for-device` hangs. Version the marker or ensure prerequisites in `dev`; bound waits and detect emulator exit.

6. **P2 — Failed runtime installation becomes “complete” on retry.** [Makefile:37](phone/Makefile:37). **Evidence:** webpack creates `dist/index.js` before the final npm install. If installation fails, subsequent make runs skip that recipe. Use a completion stamp written after all steps succeed.

7. **P2 — Dependency pinning is incomplete.** [Makefile:45](phone/Makefile:45). **Evidence:** the commit and initial `npm ci` are pinned, but the generated distribution has no supplied lockfile; its separate install resolves transitive dependencies afresh. Ship a runtime lockfile and use `npm ci`.

Process/CSP assessment: Unix process-group killing covers Node and ordinary emulator descendants. **Unverified inference:** Windows job termination may leave WSL descendants; `stop` never explicitly stops Node. WSL also needs working KVM/group access. The hash URL and frame CSP otherwise align when port 8000 and serial 5554 match. Static review only; no lifecycle execution.
