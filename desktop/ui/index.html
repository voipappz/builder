1. Your React app

Choose the local voipappz/app project you want to change. Builder creates a separate working copy for the coding agent.

Use a Git checkout of voipappz/app. On Windows, choose the checkout inside WSL (\\wsl.localhost\<distro>\…): Builder runs the app there with its Makefile.

2. Your API

The previews connect to this API for account data. The app signs in with your API login; the agent can inspect the API with read-only tools.

Use the hosted VoipAppz API. You do not need to install or run voipappz-api locally.

3. Your voice bot (optional)

To build a voice bot, choose its folder: the coding agent then changes the bot, and Builder runs it beside the app. Leave blank to change the app itself.

A folder with a builder.toml saying kind = "bot", on the same system as the app. Builder runs its make setup and make dev.

    Builder runs your app with the app’s own commands: make setup the first time (Node, packages, login), then make dev. Your API email and password, if you enter them, are what the app’s login uses. The first setup needs an internet connection and may take several minutes.
